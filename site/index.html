JARVIS

Just A Rather Very Intelligent System

Sprachgesteuerter KI-Assistent mit Bildschirm-Vision, dauerhaftem Gedächtnis, Systemsteuerung und Smart-Home-Anbindung. Er startet lokal auf deinem Rechner, öffnet ein Browser-Interface und verbindet sich mit dem KI-Anbieter deiner Wahl.

Überblick

Ein Assistent, der sieht, hört und handelt

JARVIS ist kein Chatfenster. Er sieht deinen Bildschirm, merkt sich, was du ihm sagst, steuert dein System und arbeitet To-Do-Listen selbstständig ab — mit Kill-Switch und Sicherheitsprüfung bei jedem Schritt.

jarvis — python jarvis.py

Ein Befehl, dann läuft er

python jarvis.py startet den lokalen Server, der Browser öffnet sich von selbst. Ab da sprichst oder tippst du einfach — JARVIS entscheidet, welches Modul er dafür braucht: Vision, Kalender, Gedächtnis, E-Mail oder Systemsteuerung.

Im Denkprozess links siehst du live mit, was er gerade tut: Analyse, Planung, Ausführung. Nichts passiert unsichtbar im Hintergrund.

Lokal gestartet

JARVIS läuft als lokaler Webserver auf 127.0.0.1:8765. Deine Daten liegen in ~/.jarvis/ — Gedächtnis und API-Keys verschlüsselt.

Dein KI-Anbieter

Claude, ChatGPT, Gemini, NVIDIA NIM, Mistral — oder komplett offline über ein lokales Ollama-Modell. Jederzeit in den Einstellungen umschaltbar.

Kill-Switch inklusive

Strg + Alt + J stoppt sofort alles: Sprache, Befehle, Vision, laufende To-Dos. Riskante Aktionen fragen vorher nach.

Was er kann

Funktionen im Überblick

Alle Module sind optional: Was du nicht einrichtest, wird einfach übersprungen — JARVIS startet trotzdem.

Chat & Sprache

Natürliche Unterhaltung per Text oder Stimme. Spracheingabe über den Mikrofon-Button, Sprachausgabe per TTS — in sechs Sprachen.

„Erklär mir Quantencomputing"

Bildschirm & Vision

Screenshot-Analyse mit 5-Sekunden-Countdown. Live-Vision beobachtet den Bildschirm alle 2–3 Sekunden und meldet Veränderungen per Sprache.

„Sieh dir meinen Bildschirm an"

PC-Steuerung

Mausklicks, Tastatureingaben und Programmstarts — abgesichert durch Whitelist, Risikobewertung und Injection-Schutz.

„Öffne Chrome und such nach dem Wetter"

Gedächtnis

JARVIS merkt sich Informationen dauerhaft und verschlüsselt. Alles Gespeicherte steht im Memory-Tab und lässt sich einzeln löschen.

„Merk dir, dass ich Sebastian heiße"

Code-Verarbeitung

Python wird mit py_compile geprüft, JavaScript mit node --check. Bei Syntaxfehlern korrigiert JARVIS bis zu drei Mal selbst und formatiert anschließend.

„Schreib mir ein Python-Skript für CSV-Import"

Kalender

Google Calendar lesen und Termine in natürlicher Sprache anlegen — inklusive Zeitangaben wie „Freitag 14 Uhr".

„Was habe ich morgen?"

Aufgaben

Todoist und Notion anbinden: offene Aufgaben abfragen, neue anlegen, erledigte abhaken.

„Füge zu Todoist hinzu: E-Mail beantworten"

E-Mail

Ungelesene Mails über IMAP holen, zusammenfassen, Antworten entwerfen. Gesendet wird ausschließlich nach ausdrücklicher Bestätigung.

„Fass meine E-Mails zusammen"

Daily Briefing

Wetter, Top-News per RSS, heutige Termine und offene Aufgaben — auf Zuruf oder automatisch jeden Morgen um 08:00 Uhr.

„Gib mir mein Briefing"

Dokumente

PDF (inkl. Tabellen), Word, TXT, MD, CSV, JSON, XML und HTML. Lange Dokumente werden automatisch in Abschnitte zerlegt.

„Fasse C:\Dokumente\report.pdf zusammen"

Smart Home

Home Assistant oder direkt die Philips-Hue-Bridge: Licht, Thermostat, Medien und ein Status-Überblick über alle Geräte.

„Mach das Licht an"

YouTube

Links werden automatisch erkannt, das Transkript geholt und zusammengefasst. Videos über 15 Minuten werden in 5-Minuten-Abschnitte geteilt.

„Fasse dieses Video zusammen: [Link]"

Recherche

RSS-Feeds, arXiv-Paper und die Hacker-News-Topstories zu deinen konfigurierten Themen — mit Detailansicht pro Artikel.

„Was gibt's Neues in der Forschung?"

Finanzen

Ausgaben werden aus dem Satz erkannt und kategorisiert. Monatsbudgets pro Kategorie warnen automatisch bei 80 % und 100 %.

„Ich habe 45 Euro für Lebensmittel ausgegeben"

Social Media

LinkedIn-Beiträge, X-Threads (5–8 Tweets, nummeriert) und Newsletter — jederzeit im Ton oder in der Länge überarbeitbar.

„Schreib einen LinkedIn-Post über KI in der Medizin"

Deadline-Warnungen

24 Stunden vorher als Info, 1 Stunde vorher gelb, 15 Minuten vorher rot mit Ton — aus Kalender, Aufgaben und dem Gesprächsverlauf.

„Das muss bis Freitag fertig sein"

Wake Word & Klatschen

„Hey Jarvis" aktiviert die Spracheingabe im Hintergrund. Alternativ zweimal klatschen — mit Kalibrierung auf deine Raumlautstärke.

„Hey Jarvis …"

Sicherheitssystem

Kill-Switch, Risiko-Klassifizierung jeder Anfrage, Rückfrage bei riskanten Aktionen, Programm-Whitelist und verschlüsselte API-Keys.

Installation

In drei Minuten startklar

Python installieren, Repository klonen, Installer ausführen. Der Rest passiert im Browser.

Voraussetzungen

  • Python 3.10 oder neuer
  • Windows 10/11, macOS oder Linux
  • API-Key eines Anbieters — oder lokales Ollama
  • Mikrofon & Lautsprecher (optional)

Was der Installer macht

  • prüft die Python-Installation
  • installiert alle Pakete aus requirements.txt
  • installiert System-Pakete (Audio, TTS)
  • legt ~/.jarvis/ an

Danach

  • python jarvis.py starten
  • Browser öffnet sich automatisch
  • Konfigurations-Dialog ausfüllen
  • START JARVIS klicken
Windows · empfohlen
# Repository klonen
git clone https://github.com/aquaxs1/My-Jarvis.git jarvis
cd jarvis

# Installer ausführen
install.bat
Manuell, falls der Installer nicht durchläuft
pip install -r requirements.txt

# Mikrofon-Unterstützung
pip install pyaudio

# falls das fehlschlägt:
pip install pipwin
pipwin install pyaudio
macOS
git clone https://github.com/aquaxs1/My-Jarvis.git jarvis
cd jarvis

# Audio-Bibliothek für das Mikrofon
brew install portaudio

pip3 install -r requirements.txt
Alternativ mit dem Installer
chmod +x install.sh
./install.sh
Linux · Debian / Ubuntu
git clone https://github.com/aquaxs1/My-Jarvis.git jarvis
cd jarvis

# System-Pakete für Audio und Sprachausgabe
sudo apt-get install -y portaudio19-dev python3-pyaudio espeak-ng flac

pip3 install -r requirements.txt
Alternativ mit dem Installer
chmod +x install.sh
./install.sh
Kein PyAudio? Kein Problem. JARVIS nutzt sounddevice als Fallback für das Mikrofon und startet auch ganz ohne Audio-Pakete — dann eben per Texteingabe.

JARVIS starten

Start
# Windows
python jarvis.py

# macOS / Linux
python3 jarvis.py

JARVIS startet einen lokalen Webserver und öffnet den Browser auf http://127.0.0.1:8765. Ein Boot-Screen zeigt den Fortschritt der Initialisierung. Ist der Port belegt, werden automatisch 8766, 8767 usw. probiert.

Ersteinrichtung

Beim ersten Start erscheint der Konfigurations-Dialog im Browser.

Anrede wählen

Wie JARVIS dich anspricht: Sir, Boss, Bro, Ma'am, ohne Anrede — oder eine eigene Anrede über +.

Sprachstil wählen

Professionell (präzise, Fachbegriffe), Normal (freundlich) oder Locker (Slang).

KI-Anbieter auswählen

Kachel anklicken und den API-Key eintragen. Der Key wird verschlüsselt gespeichert, nie im Klartext.

Standort eintragen

Wird für Wetter, lokale News und ortsbezogene Informationen genutzt — JARVIS fragt danach nie wieder.

START JARVIS klicken

Die Konfiguration landet in ~/.jarvis/config.json.

Nutzung

So bedienst du JARVIS

Das Interface besteht aus drei Bereichen. Alles ist per Sprache, Text oder Tastenkürzel erreichbar.

Sidebar · links

  • Denkprozess — Arbeitsschritte in Echtzeit (Analyse, Planung, Ausführung)
  • Metriken — Tokens, Sicherheitsstatus, Anzahl Erinnerungen und Routinen
  • NEUE SITZUNG — startet einen frischen Chat
  • Account — Einstellungen, Sprache, Hilfe

Chatbereich · Mitte

  • Orb-Header — Status, Uhrzeit, aktiver Anbieter, Kill-Switch
  • Nachrichten — JARVIS links, du rechts; beim Hover Kopieren und Wiederholen
  • Codeblöcke — getestet, formatiert, mit COPY-Button
  • Eingabeleiste — Mikrofon, Live-Vision, Textfeld, Senden

Panel · rechts

  • TODO — Aufgabenliste, die JARVIS selbst abarbeiten kann
  • MEMORY — alle gespeicherten Erinnerungen, einzeln löschbar
  • SUGGESTIONS — kontextbezogene Vorschläge zum Anklicken
Pulsierend türkis — bereit Leuchtend türkis — hört zu Rotierend orange — denkt nach Rot — Fehler oder Kill-Switch

Die Eingabeleiste

ElementFunktion

TextfeldTippen und mit Enter senden. Maximal 2000 Zeichen.

Sicherheit & Daten

Kontrolle bleibt bei dir

Ein Assistent, der deinen Rechner bedient, braucht eine Bremse. JARVIS hat mehrere.

Kill-Switch

Strg + Alt + J stoppt sofort alles — Sprache, Befehle, Vision und laufende To-Dos. Ein rotes Overlay legt sich über das ganze Interface.

Risikoprüfung

Jede Anfrage bekommt eine Risikobewertung. Gefährliche Aktionen werden blockiert, riskante erst nach ausdrücklicher Freigabe ausgeführt.

Verschlüsselte Keys

API-Keys liegen unter Windows in DPAPI/Credential Manager, sonst Fernet-verschlüsselt. In der config.json steht nie ein Klartext-Key.

Programm-Whitelist

Nur freigegebene Programme lassen sich öffnen. Versuche, Shell-Befehle einzuschleusen, werden erkannt und blockiert.

Keine E-Mail ohne dich

Antworten werden immer nur als Entwurf angezeigt. Versendet wird erst nach ausdrücklicher Bestätigung.

Deine Daten, dein Rechner

Konfiguration, Gedächtnis, Verlauf, Routinen und Finanzdaten liegen ausschließlich unter ~/.jarvis/ auf deinem eigenen System.

Zum Mitdenken: An den gewählten KI-Anbieter gehen die Inhalte deiner Anfragen — inklusive Screenshots, wenn du die Vision-Funktionen nutzt. Wer das vollständig vermeiden will, betreibt JARVIS mit einem lokalen Ollama-Modell.
Hilfe

Wenn etwas klemmt

Die häufigsten Stolpersteine und ihre Lösung.

Es erscheint das Banner „API Key fehlt"

Öffne die Einstellungen über das Zahnrad in der Sidebar oder mit Strg + ,, wähle deinen KI-Anbieter und trage den API-Key ein. Unter dem Feld steht anschließend „API Key active" in Grün.

Das Mikrofon funktioniert nicht

Installiere PyAudio nach. Klappt das unter Windows nicht, hilft der Umweg über pipwin. Ohne PyAudio nutzt JARVIS automatisch sounddevice.

Terminal
pip install pyaudio

# Windows-Fallback
pip install pipwin
pipwin install pyaudio
Keine Sprachausgabe zu hören

Prüfe zuerst, ob TTS in den Einstellungen aktiviert ist. Unter Linux fehlt oft die Sprachsynthese im System:

Linux
sudo apt-get install espeak-ng
Port 8765 ist belegt

JARVIS probiert automatisch die nächsten Ports (8766, 8767 …). Bleibt das Problem bestehen, beende die andere Anwendung, die diese Ports belegt.

Google Calendar meldet „credentials missing"

In der Google Cloud Console ein Projekt anlegen, die Calendar API aktivieren und eine OAuth-2.0-Client-ID (Desktop-Anwendung) erstellen. Die heruntergeladene JSON-Datei als google_credentials.json in ~/.jarvis/ ablegen und JARVIS neu starten — beim ersten Zugriff öffnet sich der Browser zur Anmeldung.

Das Wake Word reagiert nicht

Prüfe, ob der Schalter in den Einstellungen unter „Aktivierung" an ist. Ohne pvporcupine läuft die Erkennung über Google Speech Recognition und braucht eine Internetverbindung. Außerdem: Blockiert eine andere Anwendung das Mikrofon?

Die Klatsch-Erkennung löst bei Hintergrundgeräuschen aus

Drücke in den Einstellungen auf KALIBRIEREN und sei drei Sekunden still. Alternativ den Empfindlichkeits-Regler erhöhen — höhere Werte bedeuten unempfindlicher. Standardwert ist 0,30.

Muss ich alle optionalen Pakete installieren?

Nein. JARVIS startet auch ohne sie — die jeweilige Funktion wird dann übersprungen. Installiere nur, was du wirklich nutzt.
