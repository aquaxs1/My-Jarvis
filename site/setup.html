Setup

First run

Downloaded and unpacked? This is everything between starting it and talking to it.

The browser opens at 127.0.0.1:8765. Pick a provider, paste your API key, click START JARVIS. The key is stored encrypted, never in plain text.

Usage

Three panels, one input bar

Left

  • Thought process, live
  • Tokens, memories, routines
  • Settings

Center

  • Status orb and kill switch
  • Chat with tested code blocks
  • Mic · live vision · text · send

Right

  • To-dos My Jarvis runs itself
  • Stored memories
  • Suggestions
Teal — ready or listening Amber — thinking Red — error or kill switch
